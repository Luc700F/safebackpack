# Security policy

## Reporting a vulnerability

Please report security issues privately, not through a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/Luc700F/safebackpack/security/advisories/new)
for this repository. A contact email address will be added here before public launch.

Please include what you found, how to reproduce it, and what an attacker could
achieve. We aim to acknowledge a report within 72 hours.

## Scope

In scope: this repository and the deployed application.
Out of scope: findings that require physical access to a user's device, social
engineering of the operator, and reports produced solely by automated scanners
without a demonstrated impact.

Please do not run automated scans against the production deployment, and do not
access, modify or delete data belonging to other people while testing.
